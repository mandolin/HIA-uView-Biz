# Architecture Decision Records / 架构决策记录

Architecture Decision Records (ADRs) capture public decisions that shape package boundaries, contracts, compatibility, dependencies, or data handling. Each ADR records its context, decision, alternatives, consequences, and review conditions.

架构决策记录（ADR）保存会影响包边界、契约、兼容性、依赖或数据处理的公开决定。每份 ADR 都记录背景、决定、备选项、后果与复审条件。
