# Application templates / 应用模板

This directory contains private workspace packages that bind versioned declarative application-template manifests to complete, explicit capability candidates. A template package is reusable integration metadata and assembly code; it is not an application generator, copied scaffold, published app, industry preset, dependency installer, or remote catalog.

本目录包含私有 workspace package，用于把版本化声明式 application-template manifest 与完整显式 capability candidate 绑定。模板包是可复用的集成 metadata 与装配代码；它不是应用生成器、复制式脚手架、已发布应用、行业预置、依赖安装器或远端目录。

The initial `example-catalog-query-detail-mp-weixin/` template binds the neutral reference-data and catalog-query-detail slots. It supports the mandatory local mock and the explicit injected-wire fixture without discovery or fallback.

首个 `example-catalog-query-detail-mp-weixin/` 模板绑定中性 reference-data 与 catalog-query-detail slots。它支持必备本地 mock 与显式 injected-wire fixture，且不执行发现或回退。
